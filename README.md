## 🔍 What I'm Building

**[BinExplain](https://binexplain.com)** — A free, browser-based AI-powered binary analysis platform for CTF (Capture The Flag) beginners. No installation. No account. Works in any browser.

Upload a binary → Get instant CTF category detection, security protections breakdown, ROP gadgets with real addresses, a pre-populated pwntools exploit template, and AI mentor hints grounded in real past CTF solutions.

**What makes it different:**

- **Parallel AI inference** — Groq (llama-3.3-70b) and Nemotron 3 Ultra (550B MoE) run simultaneously via asyncio, merged for speed and depth
- **Evidence-bounded hints** — every generated assertion is displayed adjacent to the binary finding that warrants it, so hints are independently verifiable
- **Hybrid RAG pipeline** — 2,250+ real CTF writeups indexed across 24 technique categories, with vector similarity + technique-tag overlap scoring
- **Cache-Augmented Generation** — common binary patterns served instantly from pre-warmed cache
- **Full feature parity** between binary file and source code analysis
- **Interactive /learn curriculum** — 8 modules covering binary structure, protections, animated exploitation diagrams, and real-world CVE case studies
- **238 automated tests** covering unit, integration, CTF scenario simulation, and adversarial cases
- **Zero binary execution** — static analysis only, always
